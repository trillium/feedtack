## Installation

```package-install
npm install feedtack
```

Feedtack requires React 18+ as a peer dependency.

## Minimal setup

Wrap your app with `FeedtackProvider` and pass an adapter and user:

```tsx
import { FeedtackProvider } from "feedtack/react";
import { ConsoleAdapter } from "feedtack";

export default function App() {
  return (
    <FeedtackProvider
      adapter={new ConsoleAdapter()}
      currentUser={{ id: "u1", name: "Trillium", role: "admin" }}
    >
      <YourApp />
    </FeedtackProvider>
  );
}
```

This renders a floating "Feedback" button. Clicking it opens the feedback modal. The `ConsoleAdapter` logs payloads to `console.log` — perfect for development.

## Try it out

1. Click the **Feedback** button
2. Choose **Site**, **Page**, or click **Place a pin**
3. In pin mode, click any element on the page
4. Write a comment, pick a sentiment, and submit
5. Check your browser console for the emitted JSON payload
